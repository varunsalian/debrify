# media_kit_video_tvos

The tvOS implementation of [`media_kit_video`](https://pub.dev/packages/media_kit_video).

> Generated by [`flutter-tvos plugin port`](https://github.com/fluttertv/flutter-tvos)
> from `media_kit_video`. Read `PORTING_REPORT.md` before publishing.

## Usage

This is a federated plugin implementation. Apps that already depend on
`media_kit_video` and target tvOS only need to add this package as a
dependency:

```yaml
dependencies:
  media_kit_video: ^<latest>
  media_kit_video_tvos: ^0.0.1
```

The plugin registers automatically via Flutter's federated registry — no
explicit imports required from app code.
