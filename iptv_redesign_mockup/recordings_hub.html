Recordings Hub — as built

Design decisions

  • One page, not tabs — DVR state is small; the three zones read top-to-bottom as "now → next → done", and empty zones collapse to a one-line hint instead of a dead tab.
  • Stop lives on the card — a capture is never more than one press from ending; no menus.
  • Schedule is a header action, not a FAB — reachable in DPAD scroll order, first thing UP from the content.
  • Library rows: OK plays, RIGHT reaches delete — the same two-focusable row grammar as the cockpit stage; delete always confirms.
  • Countdown chips + elapsed timers tick from one shared 1s clock that only runs while something is live or scheduled; on TV the REC dot doesn't pulse (house rule: no standing animations).
  • Recordings older than the index survive — the library merges the store with an on-disk scan, so files recorded before this build (or by the tee) still appear.
  • Global empty state ("Your DVR is empty") with a single autofocused Schedule button when all three zones are empty.
