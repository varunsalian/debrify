Feasibility. Everything here is 2-D vector paint — gradients, clips, one bounded mask layer at most (gold sheen, glass letters, chrome sweep = a single saveLayer + blend in Flutter, the same trick ShaderMask uses). No shaders, no assets to decode before first frame. Particles and star counts halve on TV and draw batched; glows use the two-stroke idiom already shipped in the current painter instead of big blurs. The ~300 ms native window before Flutter's first frame stays a static color for all seven.
