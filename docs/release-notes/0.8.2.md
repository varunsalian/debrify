# Debrify 0.8.2 upgrade notes

## Device backup behavior

Debrify now excludes app databases, private files, preferences, and external
app state from operating-system cloud/device-transfer backups. These locations
can contain device-bound encrypted values that cannot be opened after a key or
device change. Use Debrify's own Backup & Restore feature for portable settings
and account data. Completed downloads and recordings remain public media and
are not part of a Debrify settings backup.

## Desktop launches

macOS, Windows, and Linux now run one Debrify instance per user-data directory.
A second launch securely forwards its deep link or file arguments to the
existing window and exits. An argument-free second launch probes and wakes the
primary instance without opening a second window. If the primary endpoint
cannot be reached, Debrify shows a startup failure instead of opening the same
profile databases concurrently.

## Remote compatibility

The D-pad, media buttons, and text remote remain compatible with older Debrify
receivers. Setup, addon, and credential transfers require encrypted protocol v2.
An older sender may transfer setup to this version only after explicit approval
on the receiving device; profile-enabled mode always requires an authenticated,
profile-authorized encrypted session.
