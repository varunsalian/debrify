Concept 1 — Classic Five

The literal answer to the ask: a fixed Material bottom bar. Home · Discover · IPTV · Cloud · More — one tap to the big four, everything else two taps through a grid sheet. The trick that makes five slots honest: when a "deep" tab is active, the More slot becomes that tab (icon + label, highlighted), so you always see where you are.

Why / why not

  • One-handed, glanceable, zero learning curve — this is the bar every Android user already knows; labels always on.
  • The morphing fifth slot keeps "where am I" true even inside sheet destinations — tapping it re-opens the sheet (caret hints that).
  • Weakness: the fixed four are somebody's wrong four. No-debrid users get a dead Cloud slot; Trakt users want Calendar up front; IPTV-first users don't need Discover daily. Concept 2 fixes this with the same shell.
  • Build: a Material NavigationBar + one bottom sheet; the floating glass nav stays available behind a Settings choice.
