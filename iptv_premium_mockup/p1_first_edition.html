Why this reads premium. One serif (Fraunces) reserved for exactly one thing — the programme title — so it lands like a headline. Warm ink (#0D0B09) instead of saturated navy. No filled chips, no gradients: category tabs are underlined text, badges are hairline-outlined micro-caps, buttons are one ivory pill + hairline ghosts. Focus is a 2px ivory rule on the left edge (rail, ledger, schedule all share it) — calm, unmistakable, never gold. The only colour on the page is semantic: sage for LIVE, signal red for REC.

Feature carry. Sources / Favorites / Continue / Recordings / Scheduled / custom lists with counts in the rail · Live–Movies–Series tabs + category picker · submit-only global search · EPG now/next + progress on every ledger row · time-remaining column (nobody else shows this — it's the most useful EPG number) · UHD/4K hairline badges · ★ favorites · REC state inline · hero = focused channel with Watch / Record / Favorite · stage = live preview + full-day schedule with REPLAY (catchup) and REC affordances · "Updated 4 min ago" SWR chip relocated to the footer · keycap hints kept. Phone: the ledger + hero collapse into list + bottom sheet exactly as today; the serif headline moves into the sheet.
