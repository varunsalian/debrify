Why this reads premium. Discipline. Two typefaces with strict jobs — Space Grotesk for names, JetBrains Mono for every number, time and label — and a black that is actually black. One signal colour (amber) reserved for the machinery of time: the playhead, the NOW block, the focus brackets, the elapsed meter. REC keeps its own red and nothing else gets colour at all. The ticked meters replace progress bars, corner brackets replace focus rings, and the status bar makes the page feel like it's on air even before you press anything.

The signature element is the focused-channel timeline: as you move DOWN the table, the strip above re-renders that channel's next six hours with the amber playhead pinned at "now" — the answer to "what am I committing to if I tune here" without opening a schedule. It is the stage's TODAY list made spatial; the data comes from the exact same per-channel EPG fetch (900 ms dwell, 3-concurrent budget) that feeds today's rows, so it costs nothing new. RIGHT still reaches the monitor column; the full-day pane still swaps the centre, Offstage, as today.

Feature carry. Rail in shipped order — Library (Favorites / Continue / Recordings+dot / Scheduled), Lists, Sources, Addons, counts throughout, Manage sources footer · Live/Movies/Series tabs (Xtream) · category dropdown with counts + hold-OK-to-hide · submit-only search (magnifier defers to the shell header field) · rows keep number, monogram, name, ★, resolution column (the scraped `2160P` string finally gets a home), now/next, ticked progress, end-time · REC row state + status-bar live ticker · monitor = live preview w/ tuning states, Watch / Record / Favorite, TODAY schedule with NOW/REC/REPLAY · SWR state in the status bar ("UPDATED 10:42") + progressive-load count in the footer · startup-channel, zap paging and hold-OK picker untouched. Phone: the table collapses to the classic list; the timeline becomes the sheet's header strip.
