Round 6 — Quiet Craft

Four idents built against everything that makes a splash look generated: no particles, no aurora, no lens flare, no cyan-to-magenta, no shake, no five-beat crescendo. Each one is a real material with a real process happening to it, and each has exactly one event. The type is never made of light — it is pressed, developed, cleared or cast.

All four share one composed lockup — mark inline, left of the word, on a single baseline — so the difference between them is entirely material. Every reveal settles to a completely motionless frame: the splash is held while Home prepaints behind it, so the last frame has to be still.
