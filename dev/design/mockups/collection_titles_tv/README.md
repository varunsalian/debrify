# Collection title browsing on TV

Six interactive design studies for Collection → list → movie/series cards.

Serve `dev/design/mockups` and open `/collection_titles_tv/`.

- Spotlight: large focused-title hero above a poster rail.
- Gallery: fixed preview beside an eight-poster grid.
- Cinema: full-screen artwork above landscape cards.
- Filmstrip: vertical landscape-card navigation beside a large hero.
- Atlas: a panoramic 4×2 image wall above a steady title-information band.
- Journal: a warm numbered title index beside an art print and editorial details.

Use the concept buttons, arrow keys or mouse to browse. Enter/click opens a placeholder for the existing details screen. Escape closes it. The back button previews returning to the parent collection.

Artwork is reused from `../tv_home_layouts_mockup/art/`; no API key or network image requests are needed. Content is illustrative. This is a standalone mock, not a Flutter app change. All six concepts were rendered and visually checked at 1600×1100.
