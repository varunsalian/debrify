Severity, the Apple way — a small-caps word (NONE / MILD / MODERATE / SEVERE) with a four-segment meter filled in white. Reads at ten feet, no color noise against the artwork.

Accent discipline — the poster-extracted accent (rose here) is reserved for the spoiler SHOW/HIDE toggle, matching how Spotlight uses it for the season pill and progress bars. Focus stays the house white ring.

DPAD topology — one focus node per category card (wide) or row (compact). The plate is never focusable; spoilers toggle with SELECT on the focused card, so node count never changes.
